# UniNest

UniNest is a student housing platform designed to help university students find suitable and affordable accommodation.

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Browse student housing listings
- Search and explore available properties
- Property details
- User registration and login
- Profile management
- Add property form
- Responsive design
